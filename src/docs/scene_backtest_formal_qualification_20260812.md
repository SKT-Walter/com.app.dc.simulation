# 场景回测正式资格

场景回测现在是候选策略自动发布的正式门槛，不再只是观察信息。

## 判定规则

每个回测结果都必须有历史场景重放结果，并同时满足：

- 场景历史至少 30 条 12 小时记录
- 至少有一个匹配 K 线时段
- 场景内至少 5 笔交易
- 场景内费用后收益大于 0
- 场景利润因子不低于 1.05
- 场景最大回撤不超过 25%

多品种候选按品种分别判定。任何一个品种不满足条件，该品种不会自动发布；其它满足条件的品种可以按现有 `PARTIAL_PROMOTE` / `PARTIAL_REPLACE` 规则处理。

## 安全边界

场景证据不足、重放失败或场景质量不达标时，只阻止新候选发布，不直接下线当前 ACTIVE 实盘策略。现有 live recheck 任务仍是 validation-only，不会因为复检触发发布或退休。

## 结果状态

- `QUALIFIED`: 场景资格通过，可以继续进入全周期 OOS、费用后收益和 baseline 比较
- `QUALIFICATION_FAILED`: 场景样本足够但策略在该场景质量不合格，禁止自动发布
- `INSUFFICIENT_DATA`: 场景历史或匹配交易不足，禁止自动发布
- `ERROR`: 场景重放失败，禁止自动发布
